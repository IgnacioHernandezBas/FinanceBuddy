PROJECT OVERVIEW
==================================================

Goal:
Build a financial education assistant powered by a RAG (Retrieval-Augmented Generation) system.

The assistant should help users understand:
- taxes
- mortgages
- bills
- personal finance concepts

The system must be:
- full-stack
- production-oriented
- modular and scalable
- suitable for portfolio and technical interviews

Key Requirements:
- Responses must be grounded in reliable sources
- Always show sources used
- Minimize hallucinations
- Support different explanation levels: "basic" vs "technical"
- Future support for document analysis (PDFs like invoices or mortgages)

==================================================
ARCHITECTURE DECISIONS (ALREADY MADE)
==================================================

Architecture:
- Frontend separated from backend
- React frontend
- FastAPI backend
- Modular RAG pipeline
- PostgreSQL database
- Vector search using pgvector
- Docker Compose for local development

Design Principles:
- Retrieval and generation must be decoupled
- The model is NOT the source of truth — retrieved documents are
- Every answer must be traceable to source chunks
- The system must handle:
  1. grounded answers
  2. partial answers with uncertainty
  3. safe refusal when evidence is insufficient
